# mineriadedatosv1

Proyecto Next.js 14 con App Router y Tailwind CSS

## 🚀 Tecnologías

- Next.js 14 (App Router)
- React 18
- Tailwind CSS
- ESLint

## 📋 Requisitos

- Node.js >= 18.x
- npm >= 9.x

## 🔧 Instalación

```bash
npm install
```

## 🏃 Ejecución

```bash
# Desarrollo
npm run dev

# Build para producción
npm run build

# Iniciar en producción
npm start

# Linter
npm run lint
```

## 📁 Estructura del Proyecto

```
mineriadedatosv1/
├── app/
│   ├── components/      # Componentes reutilizables
│   ├── api/             # API Routes
│   ├── layout.js        # Layout principal
│   └── page.js          # Página principal
├── hooks/               # Custom hooks
├── lib/                 # Librerías y utilidades
├── utils/               # Funciones auxiliares
├── public/              # Archivos estáticos
├── tailwind.config.js   # Configuración de Tailwind
└── next.config.js       # Configuración de Next.js
```

## 🎨 Componentes Incluidos

- **Button**: Botón con variantes (primary, secondary, success, danger)
- **Card**: Tarjeta con título y contenido

## 🔌 API Routes

El proyecto incluye un ejemplo de API Route en `/api/example`

## 🪝 Custom Hooks

- **useLocalStorage**: Hook para manejar localStorage

## 🌐 Características de Next.js

- ✅ Server Components por defecto
- ✅ Client Components con 'use client'
- ✅ API Routes integradas
- ✅ Optimización automática de imágenes
- ✅ Font optimization
- ✅ SEO-friendly
